\## תיאור המערכת



מערכת לניהול העובדים:
מערכת זו מאפשרת ניהול עובדים, שיבוץ משמרות, צפייה בלוחות עבודה ועדכון אילוצים.
המערכת מחולקת לשני מצבי עבודה עיקריים:
ההקשה והניווט במערכת היא באמצעות המספרים שמופיעים ליד כל אופציה.
למערכת יש 2 מצבים:
-	מצב משתמש (Employee User)
-	מצב מנהל כוח אדם (HR Manager)


בעת הפעלת המערכת יוצג התפריט הבא:
Choose Mode:

1. User Mode
2. HR Manager Mode
3. Load External Data
4.Erase database
4. Exit
ההסבר על האפשריות:
User Mode- כניסה של עובד למערכת.
HR Manager Mode- כניסה לניהול המערכת.
Load External Data- טעינת נתוני עובדים מוכנים מראש.
Exit- יציאה מהמערכת.

•	עובד חייב להיות קיים במערכת כדי להתחבר.
•	בכניסה ראשונה – יש להגדיר סיסמה (מינימום 4 תווים).
תפריט משתמש

5. Update Preferences - עדכון זמינות לשבוע הבא.
מאפשר לעובד להגדיר זמינות לשבוע הבא.
שלבים:
6. מוצגים האילוצים הקיימים
7. בוחרים יום בשבוע:  ראשון - 1 , שני - 2 וכך הלאה, 0 - חוזרים אחורה.
8. בוחרים סוג זמינות - בוקר, ערב, כל היום, חופש.
יש לשים לב כי האילוצים תקפים לשיבוץ לשבוע הבא בלבד ומתאפסים לאחר פרסום סידור.
9. Watch Current Week's Shifts - צפייה במשמרות העובד או לחלופין בסידור המלא של כל עובדי הסניף (של השבוע הנוכחי).
10. Watch Next Week's Shifts - צפייה במשמרות העובד או לחלופין בסידור המלא של כל עובדי הסניף (של השבוע הבא) בהנחה אם פורסמו.

12. Add Employee - הוספת עובד חדש למערכת. יש להזין את השדות הבאים: שם, תעודת זהות, סניף, חשבון בנק, שכר, סוג העסקה, תאריך התחלה.
13. ניהול משמרות  (Shifts):
יש לבחור סניף ולאחר מכן מופיעות האפשרויות הבאות:

    1. Manage Shifts Week - ניהול שיבוץ עובדים לשבוע הבא, חילופי משמרות, שעות נוספות.
יש להתחיל לעבוד על הסידור רק לאחר הדדליין ויש לפרסמו לא מאוחר מיום שבת 23:59. רק כאשר הסידור מלא (מקיים את כל הדרישות) ניתן לפרסמו (לאחר קבלת התראת בקשה).
בכניסה ראשונית עבור שיבוץ סידור שבועי חדש יש להזין מספר קופאים ומחסנאים נדרשים למשמרת (ערך אחיד לכל משמרות השבוע). ניתן לעדכן ערכים אלה בנפרד עבור כל משמרת. אין לקבוע מספר מחסנאים נמוך מהנדרש ע"י מודל ההובלות. מספר הנהגים הנדרשים מתקבל פעם אחת ממודל ההובלות ומנהל כו"א לא רשאי לשנותו.
נוהל שיבוץ/החלפה חריג/ה (Force Assign/Replace): אם וכאשר מנהל כו"א בוחר לשבץ עובד באופן חריג נשלחת בקשה לעובד ועליו לקבל/לסרב אותה בעת כניסה למערכת. קיימת אפשרות לפרסום חריג (FORCE PUBLISH) במקרה וקיימות בקשות שיבוץ לעובדים שלא אושרו.
קיימת אפשרות לאיפוס משמרת (Reset Shift) במקרים חריגים.
    2. Manual Shift Changes - שינויים ידניים במשמרות קיימות (למקרים חריגים בלבד).
    3. Get Shifts History - הצגת היסטוריית משמרות בה מופיעים פרטי כל משמרת: תאריך, ת"ז העובדים ותפקידיהם.
    4. Update Preferences Deadline - עדכון הדדליין להגשת אילוצים לשבוע הבא (ברירת המחדל - יום חמישי).
